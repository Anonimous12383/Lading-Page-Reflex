# ⚡ Power Rangers Landing Page – Reflex

Landing page inspirada en un Character Showcase moderno, creada con **Reflex** y basada en el universo de **Power Rangers**.

Incluye:

- Diseño futurista y cinematográfico
- Sección interactiva de Rangers
- Zords y clips destacados
- Efectos glow y estilo neon
- Responsive design
- Deploy con Reflex Hosting

---

# 📦 Requisitos

Antes de ejecutar el proyecto, instala:

- Python 3.11 o superior
- Poetry
- Git

---

# 🚀 Clonar el proyecto

```bash
git clone https://github.com/Anonimous12383/Lading-Page-Reflex.git
```

Entrar a la carpeta:

```bash
cd Lading-Page-Reflex
```

---

# 📥 Instalar dependencias

Instalar Poetry (si no lo tienes):

## Windows

```bash
pip install poetry
```

## Linux / Mac

```bash
curl -sSL https://install.python-poetry.org | python3 -
```

---

# ⚙️ Instalar paquetes del proyecto

```bash
poetry install
```

---

# ▶️ Ejecutar el proyecto

Iniciar la aplicación Reflex:

```bash
poetry run reflex run
```

Luego abre:

```text
http://localhost:3000
```

---

# 🌐 Deploy en Reflex Hosting

Iniciar sesión:

```bash
poetry run reflex login
```

Desplegar:

```bash
poetry run reflex deploy
```
